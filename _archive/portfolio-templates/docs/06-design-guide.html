5 レイアウトルール

レイアウト基本ルール 必須
グリッド・余白・角丸・シャドウ等の数値ルール

コンテンツ最大幅：1200px（中央寄せ）
→ 余白をしっかり取り、上質で落ち着いた印象を演出するため。

グリッドシステム：12カラムグリッド / ガター：24px
→ 柔軟なレイアウトと整った美しさを両立。

セクション間余白：PC 120px / タブレット 80px / スマホ 64px
→ ゆとりある空間で非日常感を演出。

要素間余白：大 48px / 中 24px / 小 12px
→ 情報の優先度を明確化。

角丸：基本 6px / 強調 8px
→ やわらかさと上質さのバランス。

シャドウ：通常 0 10px 24px rgba(47, 42, 40, 0.06) / ホバー 0 14px 30px rgba(47, 42, 40, 0.08)
→ 控えめで洗練された立体感。

ブレークポイント：PC 1024px以上 / タブレット 768px〜1023px / スマホ 767px以下
→ デバイスごとの最適化。
