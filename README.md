# portfolio-02

静的HTML/CSSを保ちながら、公開サイト、管理画面、Spring Boot移行準備を分けた構成です。

## Entry Points

- 公開サイト: `public-site/index.html`
- 管理ログイン: `admin/login.html`
- 管理画面トップ: `admin/index.html`
- Spring Boot移行メモ: `spring-boot/README.md`

## Folders

- `public-site/`: 公開サイト用HTML、CSS、JavaScript、画像
- `admin/`: 管理画面用HTMLと管理画面CSS
- `spring-boot/`: 設計書、プロンプト、将来のSpring Boot配置先
- `_archive/`: 旧テンプレート、検討用デザイン、未参照CSSの退避先
